# crap.games skills

Claude Code skills for making games for [crap.games](https://crap.games).

| Skill | What it does |
| --- | --- |
| `crap-games-new` | Starts a new Godot web game: naming, the [Copier template](https://github.com/mcfredrick/crap-games-template), an optional Blender art pipeline, a design doc, and deployment to `<slug>.crap.games`. It also collects patterns and gotchas learned from earlier games. |

## Install

```sh
./install.sh
```

This links each skill folder into `~/.claude/skills`, so edits here take effect right away.
